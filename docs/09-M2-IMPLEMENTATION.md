## 一次验证

在 Windows PowerShell 的项目根目录执行。前提是 WSL Ubuntu 中已有 researchpilot-mysql-1 和缓存的 alpine:3.22 镜像，沿用当前 Compose 的开发数据库凭据。

```powershell
pwsh -File ./scripts/verify.ps1
```

脚本运行 Go 检查、前端测试及构建、交叉编译集成测试，然后在共享 MySQL 网络命名空间的临时容器中执行数据库测试。使用独立数据库并在退出时清理。数据库和依赖缓存无需重复安装。

## 启动更新版本

先在 PowerShell 生成本机的模型加密主密钥。密钥保存在已忽略的 .cache/model-master.key，保留该文件才能解密已保存配置。

```powershell
pwsh -File ./scripts/init-local.ps1
```

WSL 项目目录运行 Compose。migrate 服务负责增量迁移，API 和 Worker 在迁移成功后启动。对已有数据库操作前先备份。若迁移显示 dirty，按错误检查实际已执行语句后人工修复，不自动清理数据库卷。

```bash
sudo docker compose up --build -d
```

在工作台的“模型设置”填入供应商参数和 API Key。保存后新任务使用该配置。无模型配置时继续提供演示任务，已有演示报告仍可打开。

如果模型调用需要本机代理，可通过部署环境设置 MODEL_PROXY_URL。它只用于允许列表内的模型服务，禁止重定向并保持 TLS 校验。工具的出站客户端校验公网 DNS 和实际连接 IP，不能直接复用带远程解析的通用代理。使用 Fake-IP DNS 的环境需为研究工具配置真实公网解析。
