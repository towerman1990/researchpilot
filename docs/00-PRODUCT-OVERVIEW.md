# 产品定位与决策状态

ResearchPilot 服务于需要做技术选型、理解开源项目和撰写技术决策的开发者与技术负责人。提交一个研究目标后，系统将其拆成可见步骤，检索公开资料，产出带可回查引用的 Markdown 报告。代表任务为比较两种 Go 框架的工具调用与持久恢复能力，并按团队约束给出建议。

| 状态 | 决策 |
|---|---|
| 用户已确认 | 产品聚焦技术研究。交付 Web 和独立桌面客户端。模型采用通用 OpenAI-compatible 接口。仓库名 researchpilot，可见性为公开。 |
| 沿用的设计基线 | Go 自研单 Agent Runtime、React + TypeScript、MySQL 8、Redis、Asynq、SSE、Docker Compose、Monorepo。 |
| 本稿建议，待评审 | P0 自动开跑、计划预览和取消。桌面端当前范围为 Windows。报表质量门槛及下文的超时、预算、数据保留策略。 |
| 重开评估 | HTTP 原基线 Gin、桌面原基线 Tauri 2。由 ADR 和实测决定是否更换。MyGo 的用户指代尚待确认。 |
